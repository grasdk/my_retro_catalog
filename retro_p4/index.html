Pentium 4 3GHz (LGA775)
Very high end Win98 and also good for Windows XP. For max compatibility, both Windows 98 and XP have emulated Voodoo drivers using dgVoodoo and nGlide. My first retro gaming machine attempt, which also runs DOS with SB compatible drivers. However the machines with real ISA sound cards took it's place for DOS gaming. The CPU is a SL9KG Cedar Mill P4 that runs pretty cool compared to Prescott CPUs
